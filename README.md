# 🐍 2D Snake Game (Vanilla JS)

A classic 2D Snake game built from scratch. This project is a pure implementation using **Vanilla JavaScript** and **HTML5 Canvas**, focusing on clean code and efficient game logic without relying on any external libraries or frameworks.

## 🎮 Features

* **Pure Gameplay:** Classic snake mechanics (eating food, growing longer).
* **Collision Detection:** Intelligent logic for wall hits and self-collision.
* **Score Tracking:** Real-time score updates as you collect food.
* **Performance:** High-performance rendering using the HTML5 Canvas API.
* **Responsive Logic:** Clean game loop and event-driven controls.

## 🛠 Tech Stack

* **HTML5:** Structure and the `<canvas>` element.
* **CSS3:** Styling and layout positioning.
* **Vanilla JavaScript:** Game loop, movement logic, and state management.

## 🚀 Getting Started

To run this project locally, you don't need any complex setup or node modules. Just follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/OnlineAzamat/snake-game.git](https://github.com/OnlineAzamat/snake-game.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd snake-game
    ```

3.  **Run the game:**
    Simply open the `index.html` file in any modern web browser.
    *(Tip: Use the VS Code **Live Server** extension for a better development experience).*

## 🕹 Controls

Use your keyboard arrow keys to navigate the snake:

* **⬆️ Up:** Up Arrow
* **⬇️ Down:** Down Arrow
* **⬅️ Left:** Left Arrow
* **➡️ Right:** Right Arrow
